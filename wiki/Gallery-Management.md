# Gallery Management

## Adding Images
1. Admin Dashboard > Gallery tab
2. Click Add Image
3. Enter image URL or upload file
4. Add captions in all 3 languages (Arabic, French, English)
5. Select category: event / project / program / general
6. Optionally link to specific content item
7. Check Featured to show in homepage marquee
8. Save

## Homepage Marquee
- Shows first 20 images from gallery
- Infinite CSS animation (direction-agnostic, works in Arabic RTL)
- Pauses on hover

## Editing / Deleting
Click edit or delete icons on any image card. Deletion is permanent.
