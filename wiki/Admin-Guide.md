# Admin Guide

## Access
Login > avatar menu > Admin Dashboard (or /dashboard/admin)

## Dashboard Tabs
| Tab | Purpose |
|-----|---------|
| Overview | Stats dashboard |
| News | Create/edit/delete articles |
| Events | Manage events and attendees |
| Programs | Manage programs |
| Projects | Manage projects |
| Gallery | Upload photos, set multilingual captions |
| Team | Manage team profiles |
| Testimonials | Approve/reject testimonials |
| Partners | Partner logos |
| Community | View and manage users |
| Donations | View donation records |
| Branches | Manage branch locations |
| Admins | Admin accounts and permissions |

## Permissions
manage_news, manage_events, manage_programs, manage_projects,
manage_testimonials, manage_partners, manage_users, manage_donations,
manage_branches, super_admin
