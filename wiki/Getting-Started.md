# Getting Started

## Setup
```bash
git clone https://github.com/Bosaj/les-ambassadeurs-web.git
cd les-ambassadeurs-web
cp .env.example .env
npm install
npm run dev
```Open: http://localhost:5173

## Scripts
- `npm run dev` development server
- `npm run build` production build
- `npm run lint` ESLint check
- `npm test` run Vitest
